SERVER COMMANDS

伺服器常用指令與工具清單（點擊指令區塊可直接複製）

✔ 指令已成功複製到剪貼簿！

🏡 1. 玩家高頻率實用指令

日常生存冒險中最常用到的傳送與私人通訊功能。

全玩家
/home
一秒傳送回家（直接回到當初設定家的座標）。
全玩家
/sethome
在目前站立的方塊上設定「家」的位置。
全玩家
/msg <玩家ID> <訊息>
發送只有彼此看得到的私密悄悄話（可用簡寫 /w）。
全玩家
/r <訊息>
快速回覆上一則收到的私訊。

🔐 2. 方塊私人安全鎖 (Bolt)

保護箱子與門不被偷竊的防線，預設對所有人開放使用。

全玩家
/bolt lock
輸入後按右鍵點擊箱子或門，直接進行私人鎖定。
全玩家
/bolt unlock
輸入後按右鍵點擊自己的箱子，解除鎖定。
全玩家
/bolt trust <玩家ID>
輸入後按右鍵點擊箱子，將使用權限共享給朋友。
全玩家
/bolt info
輸入後按右鍵點擊任意方塊，查詢該方塊是被誰鎖定的。

👑 3. 身份組與聊天室顏色設定 (LuckPerms)

管理員用來指派玩家階級與設定聊天標籤的權限工具。

管理員
/lp user <玩家ID> parent set admin
將某人（或自己）提升為管理員組（聊天室呈現：綠標 [管理員] + 黃色名字）。
管理員
/lp user <玩家ID> parent set verified
將某人升級為已認證玩家組（聊天室呈現：藍標 [☑已認證] + 白色名字）。
管理員
/lp user <玩家ID> parent set default
將玩家降回普通玩家組（聊天室呈現：灰標 [玩家] + 白色名字）。
管理員
/lp editor
產生安全網址，開啟網頁版的視覺化權限調整面板。

⚙️ 4. 伺服器核心維護與系統管理

維護世界規則與熱刷新外掛配置檔案的最高權限指令。

管理員
/ess reload
修改 config.yml 或 motd.txt 歡迎訊息後，一鍵重載刷新生效。
管理員
/bolt reload
修改 Bolt 的方塊防護清單（例如新增基岩鎖定權限）後，一鍵刷新生效。
管理員
/bolt admin
進入 Bolt 最高管理模式，可以直接強制拆除或檢查任何人鎖定的箱子。
管理員
/nick <玩家ID> <新暱稱>
幫指定玩家換上聊天室的專屬暱稱（清除輸入 /nick <玩家ID> off）。
管理員
/gamerule keep_inventory true
開啟麥塊原版死亡不掉落（防噴）功能。
